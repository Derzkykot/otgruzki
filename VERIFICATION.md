# Проверки первой версии

Проверено 28 октября 2026 года. Это не приёмка на реальном iPhone.

## Автоматические проверки

- Типы винтов по поставщикам, пустые новые планы, изоляция старых остатков.
- Ожидание, подтверждённый факт, подтверждённый ноль, брак и нехватка.
- Частичные выдачи без повторного вычитания свободного количества.
- Прямые передачи, приход на склад, самовывоз, брак на складе и поступление уже учтённого брака.
- Запрет невозможных фактических движений и потери уже отгруженного распределения.
- Сохранение IndexedDB между открытиями, последний созданный план, конфликт устаревшей формы.
- Полный экспорт/импорт планов и справочника, отказ повреждённому ZIP.
- Откат всей базы при ошибке в середине восстановления.
- Офлайн-HTML и модуль приложения при заголовке `Vary: Origin`.

## Ручная проверка во встроенном браузере на Mac

Использовались только искусственные данные «Проверка интерфейса» и «Проверка офлайн»; вместо документов — иконка приложения.

- Создан план Руно с ожидаемыми 700, распределены 200: свободно 500. Перезагрузка сохранила данные.
- Подготовлен офлайн-кэш. Локальный HTTP-сервер остановлен: приложение успешно загружено заново из кэша после исправления сопоставления заголовков модулей.
- При остановленном сервере создан Беркут: доступен только «73/76 новые». Добавлены клиент и локальная фотография. После повторной загрузки всё сохранилось.
- Подготовлен ZIP с фотографией; файл сохранён кнопкой «Скачать файл». Системное меню share во встроенном браузере отказало в доступе — добавлен отдельный способ скачивания и понятная ошибка.
- Файл выбран через системный диалог, проверен приложением и восстановлен после подтверждения. Фото открывается у правильного клиента.
- Из копии специально удалён файл фотографии: приложение отклонило архив до замены, текущий план и фото сохранились.
- Обновление приложения через ожидающий service worker сохранило базу.

## Не проверено

- Установка и повторный запуск с главного экрана iPhone 16 Pro Max.
- Safari/PWA в авиарежиме, камера, галерея iPhone и читаемость реальных кодов.
- Системное меню iOS «Сохранить в Файлы», включая ручной выбор iCloud Drive.
- Поведение при реальном дефиците дисковой памяти и больших объёмах фотографий.
- HTTPS-публикация: облачные сервисы и GitHub не подключались.
